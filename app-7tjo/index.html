Core16 demo build

Runs the iPhone app on a simulated iPhone on your Mac, for showing clients.

 

Download the updater

Apple Silicon Mac · Xcode installed

  1. Open the downloaded file and click through the installer. It puts Core16 Update in your Applications folder and in the Dock.
  2. Click it in the Dock. It downloads the latest build, starts a simulated iPhone, and opens the app. Give it a minute the first time.
  3. Before your next demo, click it again. If there's a newer build it fetches it; if not it just opens the app.

You only install once — after that it's the Dock icon every time.

If you'd rather use Terminal

Same thing, without the installer. Paste this once:

curl -fsSLo ~/core16-update https://core16.ca/app-7tjo/core16-update chmod +x ~/core16-update ~/core16-update

After that, just ~/core16-update any time.

No simulated iPhone yet?

Open Xcode once and let it finish installing. If the updater says it can't find a simulated iPhone, go to Xcode's settings, open Components, and download an iOS simulator runtime.
